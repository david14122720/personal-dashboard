# Personal Dashboard

## Project Overview
Private personal control center integrating finance, habits, goals, tasks, calendar, subscriptions, debts, net worth, and notes.

## Technical Stack
- **Frontend**: Next.js (Static Export) + Tailwind CSS
- **Backend**: Rust (Axum)
- **Database**: PostgreSQL (hosted on Dokploy)
